# Windows 3.5.2 성능 점검

> 과거 버전 측정입니다. 부자연스러운 프레임과 사용 중 느려짐이 보고되어 3.5.3에서 수동 CSS 재생을 제거했습니다. 아래 짧은 CPU 비교는 장시간 안정성이나 움직임의 부드러움을 입증하지 않습니다. 현재 점검은 [3.5.3](PERFORMANCE_3.5.3.md)을 참고하세요.

3.5.1과 3.5.2의 데스크톱 렌더러를 같은 macOS·Brave headless 환경에서 각각 새 브라우저로 실행했습니다. 화면은 3840×2160, 준비 시간 2초 후 약 8초간 측정했습니다. 같은 난수 시드로 고양이 초기 행동을 맞췄으며 세 조건을 변경 전·후 순서로 비교했습니다.

CPU 시간은 Chrome DevTools Protocol `SystemInfo.getProcessInfo`의 브라우저·렌더러·GPU·보조 프로세스 누적 CPU 시간 차이를 합산한 값입니다. 여러 코어를 합산하므로 실제 경과 시간보다 클 수 있습니다. 감소율은 경과 시간으로 정규화해 계산했습니다.

| 화면 | 3.5.1 CPU 누적 시간 | 3.5.2 CPU 누적 시간 | 감소율 |
|---|---:|---:|---:|
| 고양이·가구만 표시 | 57.37초 | 18.61초 | 67.6% |
| 호수 배경 · 맑음 | 39.45초 | 34.68초 | 12.1% |
| 호수 배경 · 비 | 39.10초 | 34.60초 | 11.5% |

이 수치는 Windows 작업 관리자의 점유율이 아닙니다. headless 렌더링·GPU 처리 비용을 포함하며, 각 조건을 한 차례 비교한 결과입니다. 실제 Windows PC의 그래픽 가속·모니터 주사율·화면 크기·고양이 행동에 따라 달라집니다.

기존 고양이 SVG와 동작 키프레임을 유지하고 Windows 애니메이션을 공통 24fps 시계로 구동했습니다. 입력 영역의 스타일·배치 재계산과 불필요한 네이티브 창 재배치를 줄이고, 물결·날씨 캔버스에 갱신 간격과 픽셀 예산을 적용했습니다. Windows 배경 전체 확대·축소는 멈추고 물결·구름·안개의 개별 움직임은 유지합니다. 조명·문페이즈는 눈에 띄는 변화가 없는 구간의 갱신을 줄입니다.

숨김·복원을 반복해도 프레임 루프가 중복되지 않으며, 숨겨진 동안 고양이·물결 시계가 멈추고 복원 시 재개되는지 별도 브라우저 검사와 Windows 실행 검사로 확인했습니다.

[세 Windows 배포판 실행 검사](https://github.com/CHOICHI-HWAN/horibbangu/actions/runs/40480281974)에서는 실제 트레이 팝업 표시와 항목 클릭, 재실행, 숨김·복원, 고양이 드래그, Explorer 아이콘 조작과 화면보호기도 통과했습니다.
