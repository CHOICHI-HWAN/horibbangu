# 호리빵구 이용 정책

정책 1.1 · 2026-10-27 · 정확한 조건은 루트의 [LICENSE](../LICENSE)가 우선합니다.

호리빵구는 치치박사와 아내를 위한 프로그램입니다.
로이와 동글이의 평화로운 휴식을 기리고, 모든 고양이의 행복을 바라는 마음에서 만들었습니다.

**무단 배포를 금지합니다. 허락을 받고 사용하는 것은 괜찮습니다.**
사용 허락과 재배포 허락은 구분하며, 사용 허락만으로 파일을 다른 사람에게 전달하거나
다른 사이트에 올릴 수는 없습니다. 사용·배포 허락은 [c.mario8609@gmail.com](mailto:c.mario8609@gmail.com)으로 문의해 주세요.

| 이용 | 정책 |
|---|---|
| 제작자와 배우자의 개인 이용 | 허용 |
| 그 밖의 사용자의 이용 | 제작자의 사전 허락을 받은 범위에서 허용 |
| 허락받은 이용에 필요한 설치·본인용 예비 복제 | 허용 |
| 공식 배포 주소를 링크로 소개 | 허용하되 사용·배포 허락을 대신하지 않음 |
| 코드·보호되는 그림·애니메이션·화면 구성의 재사용 | 사전 서면 허락 필요 |
| 원본·수정본 재배포·미러링·재호스팅·판매 | 사전 서면 허락 필요 |
| 본인이 원래 권리를 가진 기록·사진의 이용 | 제한하지 않음 |

권리는 각 조건을 따릅니다. 기존에 적법하게 받은 허락을 소급 취소하지 않습니다.
출처 표시나 비상업적 이용만으로 별도 허락을 대신할 수는 없습니다.
