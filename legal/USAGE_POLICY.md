# 호리빵구 이용 정책

정책 1.0 · 2026-10-23 · 정확한 조건은 루트의 [LICENSE](../LICENSE)가 우선합니다.

호리빵구는 개인적으로 보고 즐길 수 있도록 공개한 프로젝트입니다.
무료로 감상하고 실행할 수 있지만, 코드와 그림을 다른 제품에 자유롭게 가져다 쓰는
오픈소스 라이선스를 부여한 프로젝트는 아닙니다.

| 이용 | 기본 정책 |
|---|---|
| 공식 웹사이트 방문·개인 감상 | 허용 |
| 공식 Windows 파일을 본인 컴퓨터에서 개인적으로 실행 | 허용 |
| 직장 컴퓨터에서 개인적으로 감상 | 허용 |
| 정상 실행에 필요한 복제·본인용 예비 복제 | 허용 |
| 공식 웹사이트·다운로드 주소를 링크로 소개 | 허용 |
| 본인이 원래 권리를 가진 기록·사진의 내보내기와 이용 | 제한하지 않음 |
| 코드를 복사해 다른 웹사이트·앱·게임에 사용 | 사전 서면 허락 필요 |
| 보호되는 고양이 그림·애니메이션·화면 구성을 추출하여 다른 프로젝트에 사용 | 사전 서면 허락 필요 |
| 수정본·파생 서비스 공개, 원본·수정본 재배포·미러링·재호스팅 | 사전 서면 허락 필요 |
| 재판매·유료 서비스 탑재·광고 수익화 | 사전 서면 허락 필요 |
| 제작자·공식 배포본으로 오인시키거나 권리 고지를 삭제 | 허용되지 않음 |

출처 표시만 하거나 비상업적으로 사용한다는 이유만으로 재사용이 허용되지는 않습니다.
파일을 직접 전달하는 대신 공식 배포 주소를 공유해 주세요.

외부 오픈소스, 공공영역 자료, 제3자가 가진 권리 및 법령상 허용되는 이용에는 별도 조건이
적용됩니다. GitHub 플랫폼 약관에 따른 열람·플랫폼 내 포크 권리도 그대로 존중합니다.
화풍·아이디어·품종·일반적인 고양이 행동 자체에 독점권을 주장하는 정책이 아닙니다.

기존에 적법하게 받은 허락을 소급 취소하지 않습니다. AI 보조·생성 요소 역시 제작자가
적법하게 통제하는 권리 범위를 넘어서 독점할 수 있는 것으로 표시하지 않습니다.

이용 문의에는 사용할 대상, 목적, 수정 여부, 공개·배포 방식, 유료 여부와 기간을
적어 제작자의 별도 서면 허락을 받아 주세요. 공개 연락처는 현재 미지정입니다.

이 정책은 복제를 기술적으로 차단하거나 법적 집행 결과를 보장하지 않습니다.
권리자 실명·연락처 확정, 사진 제공자의 권리 확인, 실제 상업 계약·분쟁 대응은
해당 사실관계에 맞춘 검토가 필요합니다.
