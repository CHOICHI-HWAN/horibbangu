호리빵구 · 바탕화면 친구들 3.3.0 (Windows 10/11 64비트 경량판)

ZIP 안의 「호리빵구.exe」 하나만 꺼내 원하는 곳에 두고 실행하세요.
고양이 화면과 그림은 EXE에 포함되어 있어 인터넷·로그인·체중 기록이 필요 없습니다.

경량판은 PC에 설치된 Microsoft Edge WebView2 런타임을 공유합니다.
런타임이 없으면 공식 설치 안내를 열지 묻습니다. 자동 설치하지 않습니다.
런타임 설치를 원하지 않으면 별도 「호환판」 ZIP을 사용하세요.
https://horibbangu.web.app/releases/Horibbangu-Windows-Standalone.zip
호환판은 기존 3.2.1 버전이며 브라우저 엔진을 포함해 약 101 MB입니다.

기본은 제목 표시줄·테두리 없이 고양이와 가구만 나타나는 투명 화면입니다.
알림 영역의 고양이 아이콘을 클릭하면 메뉴가 열립니다.
오른쪽 클릭 → 「호수 배경 보이기」로 배경을 켜고 끌 수 있습니다.
배경 선택은 다음 실행에도 유지됩니다. 경량판 첫 실행의 기본값은 꺼짐입니다.
빈 공간은 아래 바탕화면과 다른 프로그램을 클릭할 수 있습니다.
고양이는 클릭해 쓰다듬거나 드래그해 옮길 수 있어요.
풍경 감상을 누르면 높은 캣워커에 최대 세 친구가 나란히 앉으러 가요.

Ctrl+Alt+H: 고양이 메뉴 열기 / 접기
Ctrl+Alt+Q: 종료
트레이 오른쪽 클릭: 숨기기·항상 위·친구 초대·움직임·종료
항상 위는 기본값이 꺼짐입니다.
「화면·투명도 설정…」에서 사용할 모니터와 투명도(0~80%)를 고를 수 있습니다.
투명도 0%가 가장 선명하며 슬라이더를 움직이면 바로 반영됩니다.
보통 / 항상 위에 / 항상 뒤에 모드는 서로 하나만 선택합니다.
항상 뒤에 모드는 일반 프로그램 창 뒤에 머물며 클릭해도 앞으로 나오지 않습니다.
모니터가 연결 해제되면 주 모니터를 사용하고, 다시 연결하면 선택한 모니터로 돌아옵니다.
모니터·투명도·위/뒤 설정은 자동 저장됩니다.
브라우저 엔진과 별도 언어팩은 EXE에 포함하지 않습니다.
WebView2는 설치된 공유 런타임과 시스템 기본 언어를 사용합니다.

앱 설치·관리자 권한 없이 실행됩니다. EXE 옆에 DLL을 둘 필요가 없습니다.
필요한 작은 파일과 라이선스 고지는 실행 시 사용자 폴더에 준비됩니다.
앱 파일: %LOCALAPPDATA%\HoribbanguDesktop\Native\3.3.0
창 설정: %LOCALAPPDATA%\HoribbanguDesktop\settings.ini
화면 내부 설정: %LOCALAPPDATA%\HoribbanguDesktop\WebView2
기존 Electron 호환판의 설정 폴더와는 별개입니다.
삭제하려면 앱 종료 후 EXE와 위 폴더를 지우세요.

코드 서명이 없는 개인용 빌드로 Windows의 게시자 확인 안내가 나타날 수 있습니다.
