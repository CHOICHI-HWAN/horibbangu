호리빵구 · 바탕화면 친구들 3.5.2 (Windows 10/11 64비트 경량판)

ZIP 안의 실행파일 하나를 꺼내 실행하세요. 파일명에 버전이 표시됩니다.
이전 버전이 켜져 있으면 먼저 시계 옆 트레이에서 종료해 주세요.

기본은 바탕화면 배경 모드입니다. 모든 클릭·더블클릭·우클릭·드래그·휠 입력을 아래로 통과시킵니다.
트레이의 ‘항상 위에 · 고양이 클릭/드래그’ 또는 화면 설정의 같은 체크박스를 켜면
다른 프로그램 위에서 고양이를 클릭하거나 공기방울로 옮길 수 있습니다.
이 모드에서도 고양이와 버튼 외의 빈 공간은 클릭을 통과시킵니다.
‘바탕화면 배경 · 클릭 통과’로 돌아가면 고양이 조작을 끝내고 아이콘 클릭을 우선합니다.
예전 Layer 설정만으로 항상 위에 모드를 자동 활성화하지 않습니다.

시계 옆 고양이 트레이 아이콘을 클릭하거나 우클릭해 설정 메뉴를 엽니다.
- 호수 배경 보이기: 호수와 방 배경 켜기/끄기
- 잠깐 숨기기: 전체 배경 감추기/보이기
- 화면·투명도 설정: 모니터 선택, 투명도 0~80%, 항상 위에 조절
- 고양이 메뉴 열기 / 접기: 항상 위에 모드의 화면 버튼 표시
- 쉬는 시간, 풍경 감상, 움직임 켜기/쉬기, 날씨 변경
- 기본판의 친구 초대, 날개 친구들
- 종료
Ctrl+Alt+H: 화면·투명도 설정
Ctrl+Alt+Q: 종료

모니터·투명도·배경과 항상 위에 선택은 자동 저장됩니다.
PC에 설치된 Microsoft Edge WebView2 런타임이 필요합니다.
런타임이 없으면 공식 설치 안내를 열지 묻습니다. 자동 설치하지 않습니다.
브라우저 엔진과 별도 언어팩은 EXE에 포함하지 않습니다.
고양이 그림과 동작은 EXE에 포함되어 인터넷·로그인·체중 기록 없이 실행합니다.

앱 파일: %LOCALAPPDATA%\HoribbanguDesktop\Native\3.5.2
창 설정: %LOCALAPPDATA%\HoribbanguDesktop\settings.ini
화면 내부 설정: %LOCALAPPDATA%\HoribbanguDesktop\WebView2
EXE를 옮겨도 설정은 유지됩니다. 삭제하려면 종료 후 EXE와 위 폴더를 지우세요.

시작 오류가 나면 자동으로 최대 두 번 다시 시도합니다. 계속 실패하면 오류창에 표시된 startup.log를 확인해 주세요. 기존 설정·고양이 정보는 지우지 않습니다.

화면보호기: 별도 Screensaver ZIP에는 .scr 파일 하나가 들어 있습니다.
ZIP을 풀어 .scr 파일을 계속 사용할 폴더에 보관하고, 파일 우클릭 → 더 많은 옵션 표시 → 설치를 선택하세요.
Windows 화면 보호기 설정에서 대기 시간과 다시 시작할 때 로그온 화면 표시를 선택하고 적용하세요.
화면보호기는 모든 모니터를 덮고, 마우스나 키보드 입력 시 종료됩니다. Windows 설정의 작은 미리보기도 지원합니다.
바탕화면판과 동시에 실행할 수 있습니다. WebView2 런타임은 화면보호기에도 필요합니다.

만든이: 트레이 메뉴의 ‘만든이 · 이용 안내’를 선택하세요.

앱이 켜진 상태에서 EXE를 다시 실행하면 기존 화면을 복원하고 전체 메뉴를 엽니다.
Windows 애니메이션은 원래 동작을 공통 24fps 시계로 그려 CPU 사용을 줄입니다. 잠깐 숨기면 WebView 화면 그리기도 쉽니다.
