호리빵구 · 투명 바탕화면 친구들 (Windows 64비트)

1. 「호리빵구.exe」 파일 하나만 받아 원하는 곳에 두고 실행하세요.
   ZIP으로 받았다면 안에 있는 EXE 하나만 꺼내면 됩니다.
2. DLL이나 resources 폴더를 옆에 둘 필요가 없습니다.
   필요한 파일은 실행 중 Windows 임시 폴더에 자동으로 풀리고 종료 시 정리됩니다.
   처음 실행할 때 압축 해제로 잠시 기다릴 수 있습니다.

기본은 제목 표시줄·창 테두리 없이 고양이와 가구·장식만 나타나는 투명 화면입니다.
트레이 메뉴의 「호수 배경 보이기」 또는 앱 메뉴의 「배경 켜기 / 끄기」로
할슈타트 호수와 방 배경을 표시하거나 숨길 수 있습니다. 선택은 다음 실행에도 유지됩니다.
배경을 켜면 호수·구름·안개·날씨가 움직이고 풍경 감상도 할 수 있습니다.
풍경 감상을 누르면 높은 캣워커에 최대 세 친구가 나란히 앉으러 가요.
빈 공간은 아래 바탕화면과 다른 프로그램을 클릭할 수 있습니다.
고양이는 클릭해 쓰다듬거나 드래그해 옮길 수 있어요.

메뉴: 작업표시줄 오른쪽 알림 영역의 고양이 아이콘 클릭
종료: 고양이 아이콘 오른쪽 클릭 → 종료 (또는 Ctrl+Alt+Q)
메뉴 열기 단축키: Ctrl+Alt+H
항상 위에: 트레이 메뉴에서 켜거나 끄세요. 기본값은 꺼짐입니다.
잠깐 숨기기·친구 초대·움직임 쉬기도 트레이 메뉴에서 할 수 있어요.

인터넷 연결·로그인·체중 기록·브라우저 설치가 필요하지 않습니다.
설치 과정과 관리자 권한 없이 실행됩니다.
설정은 %APPDATA%\HoribbanguDesktop 아래에 저장됩니다.

코드 서명이 없는 개인용 빌드입니다. Windows에서 게시자 확인 안내가 나타날 수 있습니다.
Mac에서 Windows용으로 패키징했으며 Windows 실기기 검증은 아직 하지 못했습니다.
